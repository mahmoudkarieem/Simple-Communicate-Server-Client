# Simple-Communicate-Server-Client
Server Application With Java
This project demonstrates a basic client-server communication model in Java.
The **Server** listens on a specific port and waits for a client connection. 
The **Client** connects to the server, sends a message, and receives a response.
It’s designed as a simple example to show how sockets, input/output streams, and message exchange work in Java.
You can run the server and client separately to see how they interact in real time.
